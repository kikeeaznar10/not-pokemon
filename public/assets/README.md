# assets — art and sound. Placeholders come from `npm run placeholders`; real files replace them at the same paths.

Since the post-M15 restyle most images are drawn by code in the style of `docs/STYLE-REFERENCE.md`: the world tileset by
`npm run world`, the sprites and the title by `npm run art` (see `tools/README.md`). The placeholder tool still fills
any path neither draws (sounds, minimaps). Replace a drawn file with real art at the same path and size as before.
