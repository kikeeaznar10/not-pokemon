# assets/sprites — flexymon (front/back 64×64, icon 16×16), characters, NPCs and items (16×16) as PNG.

Drawn by `npm run art` (post-M15 restyle; `tools/art/`): `player.png` and every `npcs/<name>.png` are 64 × 128 walk

flexymon front / back 64 × 64 (drawn at 32 × 32, scaled ×2) and icons 16 × 16, items 16 × 16, `car/audi.png` 96 × 40
(side view, nose right).
