# assets/tilesets — tileset PNGs (32×32 tiles) used by the Tiled maps.

- `world.png`: the real world's tileset, drawn by `npm run world` (art in `tools/art/tiles.ts`, 16 × 16 design
  scaled ×2). 8 columns; ids 0–31 are the base tiles, 32 and up their look-alike variants. Ids and properties:
  `public/maps/README.md`.
- `test.png`: the frozen test world's placeholder tileset, drawn by `npm run test-map` (unchanged by the restyle).
