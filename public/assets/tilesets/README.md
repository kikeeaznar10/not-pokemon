# assets/tilesets — tileset PNGs (32 × 32 tiles) used by the Tiled maps

- `world.png`: the real world's tileset, drawn by `npm run world` (art in `tools/art/tiles.ts`). 8 columns; ids 0–31
  are the base tiles, 32 and up their look-alike variants. Ids and properties: `docs/MAPS.md` › The world tileset.
- `test.png`: the frozen test world's tileset, drawn by `npm run test-map`.
