# maps — Tiled maps (.tmj, CSV layers, embedded tilesets), one per zone

Layer names: see docs/PLAN.md › Content guide. Rules the game applies (`src/data/tiled.ts`):

- Tile layers `ground`, `deco`, `above` (drawn over the player), `collision` (never drawn).
- A cell blocks if ANY tile layer has a tile whose tileset tile has the bool property `solid = true`; the map edge
  also blocks. `encounter = true` marks encounter tiles (tall grass, sand, vineyard).
- Object layer `warps` (M4): rectangles with `toMap` (zone id), `toX` / `toY` (int; leave one out to keep the
  player's column / row, as edge warps do), `toFacing` (optional: keep facing) and `trigger` (`step`: doors and
  edges, fires when a step ends inside it; `action`: press A facing it, for the car). A step warp may sit one tile
  outside the map; those off-map tiles become walkable, so walking off the edge enters it. Every door needs a
  matching warp back. Load checks: the target zone exists and every tile the warp can land on is walkable.
  M13, the Audi: a warp with the string property `car` (`murcia` on the office car, `valencia` on the car in Murcia)
  and `trigger = action` (anything else stops the game at boot). It needs no `toMap` / `toX` / `toY` / `toFacing`:
  the arrival points are `car.json › toMurcia` / `toValencia` (checked to be walkable). Draw the car itself as solid
  tiles (2 × 1) under the warp, and put the arrival point next to the car on the other side.
- Object layer `encounters` (M7): rectangles with string properties `group` (a key of the zone's `encounters` in
  `zones.json`) and `mode` (`tiles`: only tiles with `encounter = true` roll; `all`: every tile, for urban crowds).
  The first rectangle containing the tile wins. Load checks: a group missing from zones.json is an error; a group in
  zones.json that no rectangle uses is only a warning (logged at boot).
- Object layer `spawns`: point objects; the one named `default` is the zone's spawn point. Its tile is
  `floor(x / 32), floor(y / 32)`, the same numbers Tiled shows in its status bar.
- Tileset image paths are relative to the map file (e.g. `../assets/tilesets/world.png`).

## The real world (M14, redesigned in M16)

Generated by `npm run world` from the text layouts in `tools/world/` (`<zone>.txt`, one character per tile, plus
`world.json`: base ground, doors, edges, the Audi, metro / train links, encounter rectangles, spawn; see
`tools/README.md`). Edit the layout and run `npm run world -- --force`, or edit the `.tmj` in Tiled (then the layout
is out of date). Tileset `assets/tilesets/world.png` (8 × 11 tiles): ids 0–13 as the test tileset below (the trunk
and the Audi on a transparent background), then 14 sand, 15 dune grass (`encounter`), 16 mountain (`solid`),
17 vineyard (`encounter`), 18 road, 19 plaza paving, 20 roof (`solid`), 21 counter (`solid`), 22 desk (`solid`),
23 cactus (`solid`), 24 fence (`solid`), 25 bridge, 26 desert ground, 27 shelf (`solid`), 28 rock (`solid`), 29 bush
(`solid`), 30 fountain (`solid`), 31 white wall (`solid`, emblematic buildings). Ids 32–87 (M16) are listed in
`tools/world-tiles.ts › XT` with their layout characters in `tools/README.md`; `encounter` on 33–35 (onions,
lettuces, eggplants) and 86 (dry scrub), `solid` on every building, tree, water and furniture tile.

Every door is a step warp on the door tile to the interior's doormat (facing up); every interior has an off-map
warp `exit` below its doormat back to the tile under its door (facing down). Edges are off-map warps that keep the
column, with the same warp back on the other map. The metro and the train are one-way `link_<map>` step warps on the
train-door tile (`j`, top row of a station) to the platform tile under the other station's train door.

**How the world fits together.** Alboraya is on top; two edges lead south into Valencia: the road (x 42–44) and the
whole beach with its paseo (x 99–111). The metro joins Alboraya's village square to Xàtiva, next to Valencia's
Estació del Nord. El Pueblo can only be reached by the train from the Estació del Nord. Murcia is still reached only
by the Audi (plan, locked decision); it lands next to El Ciruelo. A unit test walks the whole world and checks it.

## Test maps (M3–M13, the frozen test world)

Since M14 these maps live in `public/maps/test/` and belong to the frozen test world (`public/test-world/data/`,
`src/data/world.ts`): the real game no longer lists them in `zones.json`, but dev / E2E builds load them with
`?world=test`, and the browser tests written before M14 run on them. Their tileset path is
`../../assets/tilesets/test.png`.

Generated by `npm run test-map` (see `tools/README.md`); open them in Tiled to edit. Tileset
`assets/tilesets/test.png` (local tile ids): 0 grass, 1 path, 2 wall (`solid`), 3 water (`solid`), 4 tree trunk,
