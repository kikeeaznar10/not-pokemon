# maps/test — the frozen test world's maps

These maps belong to the frozen test world (`public/test-world/data/`, `src/data/world.ts`; see
`docs/TESTING.md`): the real game never loads them, but dev / E2E builds do with `?world=test`, and most browser
tests run on them. **Do not change them**: tests depend on these coordinates. Their tileset path is
`../../assets/tilesets/test.png`.

Generated by `npm run test-map` (see `tools/README.md`); a unit test checks the files still equal its output. Tileset
`assets/tilesets/test.png` (local tile ids): 0 grass, 1 path, 2 wall (`solid`), 3 water (`solid`), 4 tree trunk,
5 tree top, 6 flowers, 7 tall grass (`encounter`), 8 collision marker (`solid`, red, hidden layer),
9 door, 10 wooden floor, 11 doormat, 12–13 the white Audi seen from above (rear, front; both `solid`).

## `test_house.tmj` — zone `test_house`, indoor, 10 × 8 (centred on a black screen)

Walls on rows 0–1 and columns 0 and 9, a cupboard at (2–3, 3), doormat and `default` spawn at (4, 7). Warp `exit`:
off-map tile (4, 8) → `test` (6, 7) facing down (just outside the door). The camarero NPC stands at (6, 4); the healer (recepcionista) at (1, 4) facing right, the storage NPC
(informático) at (8, 4) and the shopkeeper (tendero, shop `tienda_alboraya`) at (8, 6), both facing left.

## `test_east.tmj` — zone `test_east`, outdoor, 30 × 20

Path on row 10, `default` spawn at (2, 10), wall at x = 20 (y 4–15), pond x 8–11 y 2–5, trees at (5, 15), (14, 6),
(26, 13). Warp `west_edge`: off-map column x = −1 → `test` x = 29, same row. The becario NPC wanders in x 7–14,

`car = valencia`, action) stands on (2–3, 9), just above it. In the test world `test_east` plays the role of Murcia.
