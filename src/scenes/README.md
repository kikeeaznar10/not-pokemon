# src/scenes — Phaser scenes (presentation and input only; rules live in src/logic/)

| Scene (key) | File | What it does |
| --- | --- | --- |
| `Boot` | `boot-scene.ts` | Loads and validates the content JSON; looks for the sprite atlas (M15); then Preload, or Error. |
| `Preload` | `preload-scene.ts` | Loads every asset in the data (M11: also the title image, the intro coworker and the jingle), every map tileset image and the player sheet (M15: the sprites in the atlas come from its one image and are copied to textures under their own paths); shows the loading bar. When done: launches Hud (M10) and Debug when enabled, emits `game:ready` and starts Title (M11). |
| `Title` | `title-scene.ts` | The title (M11): `intro.json › titleImage` (the pixel office), the logo and a blinking "Pulsa START". Start / A / tap → menu: *Continuar* (only with a valid `flexymon.save.v1`; a broken save was copied to `flexymon.save.broken` and only *Nueva partida* shows, with "No se pudo leer la partida guardada.") and *Nueva partida*; B back to "Pulsa START". Continuar → the saved game in the Overworld. Nueva partida over a save asks "¿Empezar una nueva?" Sí / No (cursor on No) → Name. `quickStart()` is for the E2E hooks only. |
| `Name` | `name-scene.ts` | Name entry (M11): letter grid (A–Z, Ñ, á é í ó ú from `name.letters`, space, Borrar, OK); arrows + A, B deletes (on an empty name: back to Title), Start = OK, taps/clicks press cells. Turns on the Input service's text mode: letter keys (Z, X, WASD, M too), Space and Backspace type. Max 10 characters; OK with no letter says "Escribe al menos una letra.". Rules: `src/logic/name-entry.ts`. Then Intro with `{ name }`. |
| `Intro` | `intro-scene.ts` | The new-game intro (M11), scripted by `intro.json` on the `start.json › spawn` map (drawn with `drawZoneMap`): `fade_in`, `wait`, `walk` (player or coworker, one tile per direction), `face`, `say` (coworker lines, `{name}` / `{starter}`), `handover` (jingle, "¡Recibes a {starter}!", then the secret-name items and message). The new game comes from `start.json` (`newGameState`); at the end the player's tile goes into the session and the Overworld starts there. Rules: `src/logic/intro.ts`. |
| `Error` | `error-scene.ts` | Red list of content/map errors; scroll with up/down (Input service), wheel or drag. |
| `Overworld` | `overworld-scene.ts` | Draws a zone's map (loaded at boot) and moves the player on the grid; camera follows, clamped (interiors centred on black). Warps: lock, fade out 200 ms, restart on the target, fade in, unlock. Start with `{ map, x?, y?, facing?, fadeIn? }`. Emits `zone:entered`, `player:moved`; listens to `debug:teleport`, `debug:menu`, `debug:battle`, `battle:ended`. Battles (M6): `startBattle()` flashes 600 ms, launches Battle and sleeps; on `battle:ended` it wakes on the same tile, fades in and resets safe steps. NPCs (M5): spawns the zone's NPCs, which wander and block; A facing an NPC → it turns to the player and its lines show in the DialogBox, the player frozen until the last box. Owns one DialogBox and one ChoiceBox. Wild encounters (M7): after each completed step (not a warp) `checkStep()` rolls; on success the player halts on that tile and a wild battle starts (no rolls while `debugFlags.encounters` is off). Enemy NPCs (M8): after each player step (and NPC step while the player stands) `findSpotter()` checks the `ready` enemies; a spotted player halts, input locks, a "!" shows 600 ms (`NPC_ALERT_MS`), the NPC walks up (its path reserved), both face each other, it says `dialogue`, then an `npc` battle against a fresh copy of its team (`npcId` passed). A facing a `ready` enemy starts the same sequence; a `cooldown` one says `defeatDialogue`. After a win it says `defeatDialogue`; cooldowns refresh on map entry and every step. After a loss it restarts at the respawn point with "Te has despertado en la oficina..." (`messages` in the start data). M9: a `healer` heals team and storage, says "Tus flexymon están como nuevos." + its dialogue and emits `save:request` (`healer`); a `storage` / `shopkeeper` NPC opens the Storage / Shop scene after its dialogue, launched over this scene, which pauses (locked) until `overlay:closed`. M10: Start while standing still and free opens the Menu scene the same way (game time stops); every map entry asks for an auto-save (`save:request` `map`). M12: the minimap (`src/ui/minimap.ts`) top left outdoors, toggled with M / touch Mapa (not while the debug menu is open). M13: A facing a car warp (`car` property): the office car shows `car.json › lockedDialogue` unless the bag holds both items of an unlock pair (never consumed); otherwise (and always for the Murcia car) "¿Subir al Audi?" stays in the DialogBox (`hold`) with Sí / No beside it (B = No); Sí fades out, launches Car and sleeps; on `car:ended` it restarts at the car.json arrival point, fading in. |
| `Battle` | `battle-scene.ts` | The battle screen (M6), driven by `src/logic/battle.ts`. Start with `{ kind, opponent[], seed? }`; the team and bag come from `src/core/session.ts`. Plays each round's `events[]` through `viewSteps()` (`src/logic/battle-view.ts`): messages in the DialogBox (A to go on), attack sounds, shake/flash, HP bars over 400 ms, faint/switch. Menus: main 2 × 2 (Huir greyed vs NPCs), attacks + accuracy, team (fainted greyed); B goes back from every sub-menu (the forced switch after a faint cannot be cancelled); Objeto (M9): battle items with "x{n}" (`itemMenu`), then a target for heal / revive items (`itemTargetMenu`); using one plays the round (consumed, the opponent acts). After a wild win (M7): "¿Te llevas a {name}?" + ChoiceBox Llevármelo / Dejarlo (B = Dejarlo); taking it runs `takeFlexymon()` and shows the added / storage / merged / maxed message. At the end it writes the team back, fades out, asks for an auto-save (`save:request` `battle`, M10), emits `battle:ended` and stops. M8: with `npcId`, a win pays the reward (`winAgainstNpc`) and shows "¡Has ganado {n} €!"; any loss applies the Losing rule (`loseBattle`) to the game state. |
| `Car` | `car-scene.ts` | The Audi trip (M13). The Overworld launches it with `{ to: 'murcia' | 'valencia' }` and sleeps. A side-scrolling road scene drawn from shapes (sky, far mountains, bushes and road scrolling at different speeds, white speed lines, the car bobbing, the camera shaking every 900 ms) with `car.json › sprite` (side view, nose right; flipped for the way back) and `car.json › sound` looped at the effects volume. Lasts `CAR_TRIP_MS` (5 s); from `CAR_SKIP_AFTER_MS` (1 s) any button (A, B, Start, Mapa, a direction) skips it. Then it fades out, emits `car:ended { to }` and stops; the Overworld restarts at `car.json › toMurcia` / `toValencia`. Rules: `src/logic/car.ts`. |
| `Shop` | `shop-scene.ts` | The shop (M9), over the paused overworld; start with `{ shopId }`. Money box, Comprar / Vender / Salir; lists from `src/logic/shop.ts` (`buyRows`, `sellRows`: icons, prices, greyed unsellable items); quantity picker 1 … limit (Up/Down ±1, Right/Left ±`QTY_BIG_STEP`) with the total; "¿Compras / Vendes {n} × {item} por {total} €?" Sí / No; `buy` / `sell` from `economy.ts` write money and bag to the game state. B goes back a step; leaving emits `save:request` (`shop`) and `overlay:closed`. |
| `Storage` | `storage-scene.ts` | The storage box (M9), over the paused overworld. Columns Equipo (n/slots) and Caja (n) with icon, name, HP; Up/Down move, Left/Right switch column, A moves to the other column (`boxMove`: never leaves the team empty, never over its slots; refusals show a message); long columns scroll. B emits `overlay:closed` and stops. |
| `Menu` | `menu-scene.ts` | The Start menu (M10), over the paused overworld: Equipo, Mochila, Mapa, Opciones, Cerrar on the right. Equipo: team list (icon, name, PS) → detail page (front sprite, the four stats as "value (base + bonus)", attacks with accuracy) with Mover (pick the new position; first = first into battle) / Volver. Mochila: bag with "x{n}" and the description at the bottom; field items (heal / revive → pick a team member, greyed when useless; Regleta at once) run `useFieldItem`; other items greyed; empty bag says so. Mapa (M12): outdoors toggles the minimap ("Minimapa activado." / "Minimapa desactivado.", visible at once), indoors "Aquí dentro no hay mapa.". Opciones: Música / Efectos 0–10, Texto lenta / normal / rápida; Left/Right change at once (stored, applied live). B goes back a step; B, Start or Cerrar on the main list closes: `save:request` (`menu`), `overlay:closed`. Rules: `src/logic/menu.ts`, `src/logic/options.ts`. |
| `Hud` | `hud-scene.ts` | Always-on layer (M10), launched by Preload, under Debug in the scene list: shows a small "Guardando…" box at the top centre (M12; it was top right, under the touch Start / Mapa buttons) for 600 ms (`SAVE_ICON_MS`) on every `save:done`. Reads no input. The `currentScene()` hook ignores it. |
| `Debug` | `debug-scene.ts` | Dev-only overlay (dev builds or `?debug=1`). F2 cycles hidden → info (map, tile, FPS) → teleport menu (up/down, A = go to the zone's `default` spawn, B = close; below the zones one "Combate: {name}" entry per flexymon starts a wild battle, M6; last, under "Opciones", "Encuentros: sí/no" toggles wild encounters and keeps the menu open, M7; "NPC: todos listos" sets every enemy NPC `ready`, M8; "Borrar partida", first under Opciones, M10: `debug:delete_save` → `main.ts` stops auto-saving, deletes `flexymon.save.v1` and reloads the page) → hidden. The info lines show the euros (M8). M15: groups "Dar" ("Dar 1000 €", then "Dar: {item}" per item; the menu stays open) and "Datos" ("Recargar datos": reload and validate every JSON and map without a page reload; on success the game state is checked against the new data, new sprites / sounds load and `debug:reloaded` makes the Overworld rebuild the map where the player stands; on error the old data stays and the overlay shows "Error al recargar (n)" with the first errors) between the battles and Opciones. The menu draws a 14-line window that follows the cursor (the hook `debugLines()` still returns every line). Last in the scene list so it draws on top. |

Scenes read controls only through `src/core/input.ts` (Phaser's keyboard plugin is turned off in `src/config/game.ts`).

Interface sounds (M15, `src/core/ui-sound.ts`): menus and choice boxes play `cursor` / `confirm` / `cancel` (and `error` on a greyed option); Title, Name, Menu (Opciones page, Start to close), Shop (picker, refusals, `money` on a deal), Storage (moves, refusals) and Battle (`money` on an enemy's reward) add their own.
