# src/scenes — Phaser scenes (presentation and input only; rules live in src/logic/)

| Scene (key) | File | What it does |
| --- | --- | --- |
| `Boot` | `boot-scene.ts` | Loads and validates the content JSON; then Preload, or Error. |
| `Preload` | `preload-scene.ts` | Loads every asset in the data, every map tileset image and the player sheet; shows "Flexymon" + "Pulsa START". Start / A / tap → Overworld at `start.json › spawn` (Title replaces this in M11). Launches Debug when enabled. |
| `Error` | `error-scene.ts` | Red list of content/map errors; scroll with up/down (Input service), wheel or drag. |
| `Overworld` | `overworld-scene.ts` | Draws a zone's map (loaded at boot) and moves the player on the grid; camera follows, clamped (interiors centred on black). Warps: lock, fade out 200 ms, restart on the target, fade in, unlock. Start with `{ map, x?, y?, facing?, fadeIn? }`. Emits `zone:entered`, `player:moved`; listens to `debug:teleport`, `debug:menu`, `debug:battle`, `battle:ended`. Battles (M6): `startBattle()` flashes 600 ms, launches Battle and sleeps; on `battle:ended` it wakes on the same tile, fades in and resets safe steps. NPCs (M5): spawns the zone's NPCs, which wander and block; A facing an NPC → it turns to the player and its lines show in the DialogBox, the player frozen until the last box. Owns one DialogBox and one ChoiceBox. Wild encounters (M7): after each completed step (not a warp) `checkStep()` rolls; on success the player halts on that tile and a wild battle starts (no rolls while `debugFlags.encounters` is off). Enemy NPCs (M8): after each player step (and NPC step while the player stands) `findSpotter()` checks the `ready` enemies; a spotted player halts, input locks, a "!" shows 600 ms (`NPC_ALERT_MS`), the NPC walks up (its path reserved), both face each other, it says `dialogue`, then an `npc` battle against a fresh copy of its team (`npcId` passed). A facing a `ready` enemy starts the same sequence; a `cooldown` one says `defeatDialogue`. After a win it says `defeatDialogue`; cooldowns refresh on map entry and every step. After a loss it restarts at the respawn point with "Te has despertado en la oficina..." (`messages` in the start data). |
| `Battle` | `battle-scene.ts` | The battle screen (M6), driven by `src/logic/battle.ts`. Start with `{ kind, opponent[], seed? }`; the team and bag come from `src/core/session.ts`. Plays each round's `events[]` through `viewSteps()` (`src/logic/battle-view.ts`): messages in the DialogBox (A to go on), attack sounds, shake/flash, HP bars over 400 ms, faint/switch. Menus: main 2 × 2 (Huir greyed vs NPCs), attacks + accuracy, team (fainted greyed); B goes back from every sub-menu (the forced switch after a faint cannot be cancelled); Objeto = "Pronto" until M9. After a wild win (M7): "¿Te llevas a {name}?" + ChoiceBox Llevármelo / Dejarlo (B = Dejarlo); taking it runs `takeFlexymon()` and shows the added / storage / merged / maxed message. At the end it writes the team back, fades out, emits `battle:ended` and stops. M8: with `npcId`, a win pays the reward (`winAgainstNpc`) and shows "¡Has ganado {n} €!"; any loss applies the Losing rule (`loseBattle`) to the game state. |
| `Debug` | `debug-scene.ts` | Dev-only overlay (dev builds or `?debug=1`). F2 cycles hidden → info (map, tile, FPS) → teleport menu (up/down, A = go to the zone's `default` spawn, B = close; below the zones one "Combate: {name}" entry per flexymon starts a wild battle, M6; last, under "Opciones", "Encuentros: sí/no" toggles wild encounters and keeps the menu open, M7; "NPC: todos listos" sets every enemy NPC `ready`, M8) → hidden. The info lines show the euros (M8). Last in the scene list so it draws on top. |

Scenes read controls only through `src/core/input.ts` (Phaser's keyboard plugin is turned off in `src/config/game.ts`).
