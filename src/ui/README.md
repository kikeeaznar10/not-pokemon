# src/ui — reusable UI widgets (presentation only; rules live in src/logic/)

| File | What it is |
| --- | --- |
| `dialog-box.ts` | `DialogBox`: 512 × 80 box at the bottom, fixed to the camera. Text types out at the text speed option (lenta 15, normal 30 = `TEXT_CPS`, rápida 60 characters/s, `TEXT_SPEED_CPS`); A shows the whole box, A again goes to the next; a blinking arrow when another box follows; word wrap and overflow onto extra boxes (`src/logic/dialogue.ts`); plays the speaker's `voice` every 3 characters at the effects volume option. The owner calls `update(dt)` each frame while `isOpen`; the opening frame ignores input. `open(lines, { hold: true })` makes a question box: A no longer closes the last box, it stays under a ChoiceBox until the owner calls `dismiss()` ("¿Subir al Audi?"). |
| `choice-box.ts` | `ChoiceBox`: framed option list with a cursor (Sí/No, Llevármelo/Dejarlo, the shop's Comprar/Vender/Salir). Up/Down wrap, A chooses, B cancels (`null`) unless `cancelable: false`. Sits at the right edge above the DialogBox by default. |
| `cursor.ts` | `moveCursor`: wrap-around cursor movement; `moveGridCursor`: grid movement without wrapping. Pure (unit-tested). |
| `grid-menu.ts` | `GridMenu`: framed options in `cols` columns with a cursor (battle 2 × 2 menu, attack list, team list). Arrows move, A chooses an enabled option (disabled ones are greyed and ignore A), B cancels unless `cancelable: false`. Options may have an icon and a right-aligned text; optional title line; `onMove` for side panels. Lists longer than the frame scroll (window follows the cursor, arrows on the right edge; `state().firstRow`). |
| `frame.ts` | `framedBox`: the shared box look, a cream fill (`FRAME.fill`) inside a dark outer line (`FRAME.border`) and a soft blue inner line (`FRAME.accent`). Used by DialogBox, ChoiceBox, GridMenu and the Battle, Shop, Menu, Name and Title panels; the Storage and Menu full-screen backgrounds use the same colours. |
| `hp-bar.ts` | `HpBar`: HP bar (green / yellow < 50 % / red < 20 %, `hpColor`), optionally with "PS 31/40". `set()` jumps, `animateTo()` moves over `HP_ANIM_MS` (400 ms). `shown` is the drawn value (E2E). |

| `minimap.ts` | `Minimap`: the zone's `assets/ui/minimap_<zone>.png` in the top-left corner (unscaled, or shrunk to fit `MINIMAP_MAX_W × MINIMAP_MAX_H`), a blinking dot (`MINIMAP_BLINK_MS`) on the player's tile (`src/logic/minimap.ts`). Hidden indoors and when the image is missing. `minimapPrefs.shown` / `toggleMinimap()` (M, touch *Mapa*, Start menu *Mapa*) apply at once to every live minimap, even while the overworld is paused; the choice lasts for the page (not saved). |
| `touch-controls.ts` | `TouchControls`: HTML overlay (not canvas) on touch devices (`isTouchDevice`: `(pointer: coarse)`): D-pad bottom left, A / B bottom right, Start / Mapa top right, semi-transparent, every target ≥ 48 CSS px (`TOUCH_MIN_PX`; styles in `index.html`). Feeds `input.press/release` with sources `touch:<id>:<pointerId>` / `touch:dpad`, so it works  text mode. Multi-touch by pointer id; the D-pad direction comes from the finger's position (`dpadDirection`, dead zone `DPAD_DEAD_ZONE`), so sliding changes direction without lifting. Cancels every touch default on the controls; `preventBrowserGestures` blocks page zoom / scroll. `view()` for the E2E hooks. |
| `rotate-screen.ts` | `RotateScreen`: on touch devices, a black HTML "Gira el móvil" screen while the page is taller than wide (`isPortrait`); `main.ts` pauses the game loop and sound meanwhile. `requestFullscreenOnFirstTap`: the first finger lifted asks for fullscreen and a landscape lock (errors ignored; iPhone Safari has none). |

The Start menu is a scene (`src/scenes/menu-scene.ts`) built from `GridMenu` and `DialogBox`. Text uses the browser's monospace font until a
pixel font asset exists (see `docs/ART.md`). Widgets read controls only through `src/core/input.ts`.
